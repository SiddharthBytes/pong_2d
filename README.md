# PongSurvival
## tagline
**hit till infinity**
## Description
this is just a pong inspired game unlike normal pong it dont have two paddle or two player<br>
this has only a single paddle control by player and it hit wall and comeback to player<br>
we count a point each time player hit the ball and display it on score written as SCORE

## ending
just like classic pong it has no ending that's why our tagline is **hit till infinity**

## how it is created
1.godot as main engine<br>
2.gdscript as scripting language<br>

## specialities
it is just build using 2 colors and there shade and yet it looks awsome<br>
the colors are blue and black

## assets
all the assets are created with pixel art with pixel studio

## background music
as for background music i have choosen the famous 365 game theme that is used in<br>
in many retro games to give old players the feelings they grew with 

## GENERATIVE AI USAGE
no generative ai is used since mentioned all the assets are created by me expect for music

## ACTIONS
for moving up the paddle press **PgUp**<br>
for moving down press **PgDn**
